# LKK AI Builder Community Lesson

「AI 先锋（内部 FDE）」课程展示网站。单文件 HTML，纸感米白 + 宋体 + 朱红，无框架、无构建、无外部依赖。

## 打开方式

直接用浏览器打开 `AI先锋课程表.html` 即可（双击或拖入浏览器）。不需要安装依赖、不需要起服务，也不需要任何账号或密钥。

## 功能

- 四个视图：总览、课程表、工具矩阵、认证，页内 hash 路由切换
- 课程表按层次（基础 / 进阶 / 结业）和类别（A–E）筛选，实时计数
- 点击卡片打开模块详情抽屉：目标、课上做什么、工具、交付、考核
- 中英文切换：导航栏右侧 EN / 中文按钮，覆盖四个视图、全部卡片与抽屉、筛选计数
- 语言选择保存在浏览器 `localStorage`（键 `abp-lang`），刷新后保留，默认中文

## 课程结构

12 周、每周一课、12 个模块：基础层 7 课（M01–M05、M07、M08）、进阶层 4 课（M06、M09–M11）、第 12 周 Capstone 结业答辩。

## 文件

- `AI先锋课程表.html`：网站本体，全部样式、脚本和课程内容都在这一个文件里
- `docs/handover.md`：运行、验证、回滚与遗留事项

## 修改方式

直接编辑 HTML 内的中文文案即可。需要同步英文时，改同一元素上的 `data-en` 属性；`data-zh` 由页面在首次切换语言时自动保存，不用手改。

# 交接说明

## 运行与配置

- 纯静态单文件，浏览器直接打开 `AI先锋课程表.html`。
- 无构建步骤、无后端、无外部资源请求，不需要任何配置或凭据。
- 部署时把整个 HTML 放到任意静态托管即可，入口就是这个文件。
